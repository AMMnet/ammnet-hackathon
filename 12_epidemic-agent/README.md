# Live Session 12: Working with an AI Coding Agent

**Epidemic Forecasting from Partial Outbreak Data**

Nguyen Tran · 10 November 2026 · 05:00–07:00 UTC

- [Read the participant guide online](https://labs.ammnet.org/12_epidemic-agent/).
- [Download the clean starter ZIP](epidemic-agent-starter.zip) and extract it into a new project folder.
- [Read the Markdown participant guide](participant-guide.md).

The starter contains only `WORKSHOP_BRIEF.md` and `data/observed.csv`.
Individual copies are also available here. The CSV contains eight two-week
observations; the facilitator supplies biweeks 9–16 after forecasts are frozen.

No advanced programming or individual Codex access is required to follow the
facilitator-led session. To run the workflow yourself, see the guide's setup
instructions for Codex, Python packages, and optional Git.

Use a fresh copy of the starter for the formal challenge. Open the extracted
starter folder in your coding agent, rather than this entire repository: other
sessions contain unrelated outbreak materials.
